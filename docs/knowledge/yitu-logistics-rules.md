# 驿途物流服务规则与常见问题指南

> **文档版本**：`rules-v1`  
> **规则状态**：演示基线（待运营确认，不作为正式服务承诺）  
> **适用范围**：北京、上海、广州、深圳演示网点及同类国内线路  
> **时区**：Asia/Shanghai（东八区，UTC+08:00）  
> **货币**：人民币，系统内部以「分」存储，本文以「元」说明

本指南汇总了驿途智能物流平台的寄递规则、计费标准、时效承诺、禁限寄物品清单与常见问题，供客户咨询与 AI 客服解答参考。涉及最终运费、承诺时间、赔付责任等关键结论时，以系统结构化业务数据为准，本指南仅作政策解释。

---

## 一、服务概览

驿途提供跨城市快递履约服务，覆盖从客户寄件到收件人签收的完整流程。

### 1.1 寄件方式

| 寄件方式 | 说明 |
| --- | --- |
| 上门揽收（DOOR_PICKUP） | 快递员按预约时间上门取件，需额外收取上门服务费 |
| 网点自寄（STATION_DROPOFF） | 客户自行前往直营网点寄件，免收上门服务费 |

### 1.2 收件方式

| 收件方式 | 说明 |
| --- | --- |
| 送货上门（HOME_DELIVERY） | 快递员将包裹派送至收件地址，费用已含在基础运费中 |
| 网点自取（STATION_PICKUP） | 包裹到站后生成一次性取件码，由收件人到网点自取，可享运费优惠 |

### 1.3 服务组合

四种寄收件方式可自由组合：

1. 上门揽收 + 送货上门
2. 上门揽收 + 网点自取
3. 网点自寄 + 送货上门
4. 网点自寄 + 网点自取

网点自寄不产生揽收任务；网点自取不产生派送任务。

## 二、服务范围与网点

### 2.1 已开通城市

目前预置开通以下城市的直营网点及服务区：

- 北京
- 上海
- 广州
- 深圳

每座城市至少设有 2 个直营网点，具体服务范围以对应区县编码匹配结果为准。

### 2.2 网点匹配规则

- **上门揽收**：根据寄件地址的区县编码自动匹配始发网点。
- **网点自寄**：列出寄件区县内可用网点，由客户自行选择。
- **送货上门**：根据收件地址的区县编码匹配目标网点。
- **网点自取**：由客户选择目标自提网点。

### 2.3 未开通地区

若寄件或收件地址未匹配到任何网点，系统会提示「该地区暂未开通服务」。此时可联系运营管理员，确认是否可人工指派网点并提供审计原因。

## 三、营业时间与工作日历

- **营业时间**：每日 09:00 — 18:00，午间不暂停计时。
- **工作日**：周一至周六；周日不计入工作小时。
- **法定节假日**：由运营管理员维护节假日表，节假日默认不计工作小时。
- 干线运输按自然时间估算；揽收、网点处理和派送按工作小时计算。

## 四、禁寄与限寄物品

> 本节是寄递前必须核对的核心规则。寄件人须保证所寄物品不属于禁寄物品，且限寄物品符合寄递条件。

### 4.1 禁寄物品（绝对禁止寄递）

以下物品一律禁止寄递：

| 类别 | 示例 |
| --- | --- |
| 枪支、弹药及管制器具 | 枪支、弹药、管制刀具、弓弩、电击器、甩棍 |
| 爆炸性物品 | 烟花爆竹、火药、雷管、炸药 |
| 易燃液体 | 汽油、煤油、酒精、油漆稀释剂、打火机油 |
| 易燃气体与固体 | 打火机、气雾罐、火柴、固体酒精 |
| 氧化剂与过氧化物 | 高锰酸钾、双氧水（高浓度）、漂白粉原料 |
| 有毒物质 | 农药、杀虫剂、毒鼠药、氰化物、水银 |
| 放射性物质 | 含放射性核素的物品 |
| 腐蚀性物质 | 强酸、强碱、蓄电池漏液 |
| 麻醉药品与精神药品 | 毒品、吸毒工具、未获许可的处方麻醉药 |
| 非法出版物与违禁宣传品 | 反动、淫秽、迷信等非法印刷品及音像制品 |
| 假冒伪劣与侵权商品 | 假币、假证件、伪造票据、侵犯知识产权的商品 |
| 受保护动植物及其制品 | 象牙、犀牛角、受保护野生动植物制品 |
| 国家明令禁止流通的文物与货币 | 禁止出境文物、伪造货币 |
| 活体动物 | 受保护的及无法保证存活条件的活体动物 |
| 不明性质的粉末与危险品 | 无法说明成分与性质的粉末、疑似危险品 |

### 4.2 限寄物品（符合条件方可寄递）

以下物品在满足特定条件时可以寄递，否则拒收：

| 物品 | 寄递条件 |
| --- | --- |
| 锂电池、充电宝 | 仅限陆运；单块额定能量不超过 100Wh（约 20000mAh），须独立绝缘包装，单次限 2 块 |
| 含锂电池的电子产品 | 手机、笔记本、相机等，需关机并防震包装，电池内置且状态良好 |
| 液体类（化妆品、饮料等） | 容器密封、防漏包装，单独用气泡膜包裹后放入硬质外箱 |
| 食品 | 在保质期内，真空或密封包装；易腐、需冷藏食品不支持寄递 |
| 药品 | 非处方药可寄；处方药、麻醉类、精神类药品按限寄规定执行 |
| 家用刀具（菜刀、水果刀） | 刀刃须固定并包裹，不得外露，放入硬质包装 |
| 烟草与酒类 | 香烟限量（一般不超过 2 条），酒类需原包装密封、防震，超量按禁限寄处理 |
| 磁性物品 | 需屏蔽包装，避免影响其他包裹与设备 |
| 粉末状物品 | 需说明成分与性质，密封包装，无法说明的按禁寄处理 |
| 现金与有价证券 | 原则上不接受寄递；确需寄递的，不享受保价且风险自担 |

### 4.3 常见物品速查

| 物品 | 能否寄递 | 说明 |
| --- | --- | --- |
| 充电宝 | ✅ 限寄 | 单块 ≤ 100Wh，独立绝缘包装，单次限 2 块，仅陆运 |
| 手机、笔记本电脑 | ✅ 限寄 | 关机、防震包装 |
| 化妆品、护肤品 | ✅ 限寄 | 密封防漏包装 |
| 普通食品、零食 | ✅ 限寄 | 保质期内、密封包装 |
| 药品（非处方） | ✅ 限寄 | 非处方药可寄 |
| 菜刀、水果刀 | ✅ 限寄 | 刀刃固定包裹 |
| 酒类 | ✅ 限寄 | 原包装密封、防震、限量 |
| 香烟 | ✅ 限寄 | 一般不超过 2 条 |
| 打火机、烟花、汽油 | ❌ 禁寄 | 易燃易爆 |
| 现金、证件原件 | ⚠️ 不建议 | 不保价、风险自担 |
| 活体动物 | ❌ 禁寄 | 无法保证存活条件 |

> 如无法判断物品是否可寄，请在下单前咨询客服或网点工作人员。违规寄递禁限寄物品的，网点有权拒收，已收寄的将按相关规定处理。

## 五、包装规范

### 5.1 通用要求

1. 物品须使用坚固、完好的外包装，能承受正常运输过程中的挤压、颠簸与堆叠。
2. 包装内部须填充缓冲材料（气泡膜、泡沫、充气袋等），避免物品在箱内晃动。
3. 外包装须用胶带封口牢固，边角加固；易碎品须在外箱明显位置标注「易碎」。
4. 液体、粉末须密封后再套防水袋，防止泄漏污染其他包裹。
5. 多个物品合装时，须分别独立包裹，防止相互碰撞。

### 5.2 分类包装要求

| 物品类型 | 包装要求 |
| --- | --- |
| 易碎品（玻璃、陶瓷、电子产品） | 双层包装，缓冲材料包裹，外箱标注「易碎」 |
| 液体 | 密封容器 + 防水袋 + 硬质外箱 |
| 粉末 | 密封袋 + 防漏外包装 |
| 文件、票据 | 防水袋 + 硬质文件封 |
| 衣物、纺织品 | 防潮袋包装 |

包装不合规的包裹，揽收员或网点工作人员有权要求重新包装或拒收。

## 六、计费与价格

### 6.1 计费重量

```text
体积重量 = 向上取整(长 × 宽 × 高 ÷ 8000)
计费重量 = max(实际重量, 体积重量)
计费档位 = 向上取整(计费重量 ÷ 500 克)
```

- 首重覆盖 1 千克（1000 克）。
- 超过首重后，每 500 克为一个续重档位向上进位。例如计费重量 1.2 千克，按 1.5 千克计算。
- 重量单位按克、尺寸按厘米计算，避免浮点误差。

### 6.2 区域价格表

| 区域线路 | 首重（1kg） | 续重（每 0.5kg） | 说明 |
| --- | ---: | ---: | --- |
| 同城（如北京—北京、上海—上海） | 8 元 | 2 元 | 同一城市服务区 |
| 普通跨区 | 12 元 | 5 元 | 非偏远、非演示主线路 |
| 北京—上海演示主线路 | 15 元 | 6 元 | 当前阶段标准演示路线 |
| 偏远地区附加 | +6 元 | +3 元 | 仅在命中偏远区域规则时追加 |

### 6.3 服务费用

| 项目 | 金额 | 说明 |
| --- | ---: | --- |
| 上门揽收 | +3 元 | 快递员上门取件 |
| 网点自寄 | 0 元 | 客户到店寄件 |
| 送货上门 | 0 元 | 已含在基础运费中 |
| 网点自取 | -1 元 | 优惠后总价不低于 0 元 |

### 6.4 保价费

| 项目 | 规则 |
| --- | --- |
| 保价费 | 声明价值 × 0.3%，最低 1 元 |
| 未保价 | 保价费为 0 元，赔付按未保价标准执行 |

### 6.5 最终费用

```text
应付金额 = 首重费 + 续重费 + 区域附加费 + 服务费 + 保价费 - 优惠
```

- 报价接口会返回分项明细、总金额、计费重量、规则版本与有效期。
- 系统不接受客户端直接提交总金额，费用由系统按规则确定性计算。

### 6.6 复重、补差价与退款

- 客户填写的重量、尺寸由揽收员或网点员复核。
- 复核重量不变或变低：保留原报价，不自动退款。
- 复核重量变高：生成补差价，未补款前不得发运。
- 揽收前取消：全额退款；揽收后的取消、拦截、退回费用由异常规则决定。

## 七、时效与送达

### 7.1 客户承诺时效

| 服务组合 | 同城 | 北京—上海主线路 | 普通跨区 |
| --- | --- | --- | --- |
| 上门揽收 + 送货上门 | 支付后 1 个工作日 | 支付后 3 个工作日 | 支付后 4 个工作日 |
| 上门揽收 + 网点自取 | 支付后 1 个工作日 | 支付后 3 个工作日 | 支付后 4 个工作日 |
| 网点自寄 + 送货上门 | 始发网点验收后 1 个工作日 | 始发网点验收后 2 个工作日 | 始发网点验收后 3 个工作日 |
| 网点自寄 + 网点自取 | 始发网点验收后 1 个工作日 | 始发网点验收后 2 个工作日 | 始发网点验收后 3 个工作日 |

- 「支付后」从支付成功时间起算；「始发网点验收后」从网点确认收件时间起算。
- 承诺时间（promised_delivery_at）在下单时冻结，是服务承诺，不是预计时间。发生异常时原承诺保留并标记暂停或违约原因。

### 7.2 预计送达时间（ETA）

- 承诺时间（promised_delivery_at）：下单时承诺的最晚送达时间，冻结不变。
- 预计送达时间（estimated_delivery_at）：根据最新轨迹与剩余阶段标准时长动态更新。
- 实际签收时间（delivered_at）：实际签收或自取核销时间。

## 八、下单与寄件方式

### 8.1 下单方式

客户可通过以下任一方式下单，两者共用同一业务服务：

1. **AI 对话下单**：通过自然语言描述需求，AI 逐项补全信息并生成确认卡片。
2. **表单下单**：手动填写寄收件信息、物品、重量、尺寸等。

### 8.2 下单所需信息

- 寄件人与收件人的姓名、电话、地址（省、市、区、详细地址）。
- 物品名称、品类、实际重量与尺寸。
- 寄件方式（上门揽收或网点自寄）。
- 收件方式（送货上门或网点自取，自取需选择自提网点）。
- 是否保价及声明价值（可选）。

### 8.3 上门揽收

1. 下单并支付后，系统根据寄件地址自动匹配始发网点并生成揽收任务。
2. 快递员接单后按约定时间上门取件，并复核物品、重量与尺寸。
3. 重量复核变高时进入补差价状态，补款完成后才发运。

### 8.4 网点自寄

1. 客户选择寄件区县内的可用网点。
2. 携带包裹到店，网点人员验收物品是否合规、包装是否合格。
3. 验收通过后入站，进入后续运输流程。不合规物品将被拒收。

## 九、收件方式与取件码

### 9.1 送货上门

- 包裹到达目标网点后，系统生成派送任务。
- 派送员接单后上门派送，配送前可电话联系收件人。

### 9.2 网点自取

1. 包裹到达目标网点后，系统生成一次性取件码（6 位）。
2. 取件码通过站内通知或短信发送给收件人。
3. 收件人到网点出示取件码，网点人员核验收件人信息与运单后完成签收。

### 9.3 取件码规则

- 取件码默认有效期 30 分钟，重新签发会使旧码失效。
- 连续输错 5 次将锁定，由网点人员核验收件人信息后重新签发。
- 取件码在包裹离开自取网点、成功核销或运单结束时失效。
- 取件码仅以哈希形式存储，系统与日志不会保存取件码明文。

## 十、签收规则

### 10.1 签收方式

签收时系统会生成签收凭证（ProofOfDelivery），记录以下信息：

- 本人签收、他人代收或网点自取。
- 签收人脱敏姓名、核验方式、签收时间、操作人与网点。

### 10.2 代收与拒收

- **他人代收**：需记录代收人信息与核验方式。
- **拒收**：收件人拒收后，由运营管理员选择重新派送、改为网点自取或发起退回。

## 十一、保价与赔付

### 11.1 保价

- 客户可对包裹声明价值并缴纳保价费（声明价值 × 0.3%，最低 1 元）。
- 未声明价值的包裹，保价费为 0，赔付按未保价标准执行。

### 11.2 赔付原则

> 以下为演示基线，具体赔付以运营确认后的正式赔付政策为准。

- **已保价**：按声明价值与实际损失中较低者赔付，最高不超过声明价值。
- **未保价**：按运费的一定倍数（演示基线为 3 倍运费）与实际损失中较低者赔付。
- 因禁限寄物品违规寄递、包装不合规、不可抗力等原因造成的损失，不在赔付范围内。
- 赔付责任由运营管理员依据规则与凭证判定，AI 不能独立裁决赔付金额。

## 十二、取消、拦截与退回

### 12.1 取消

| 阶段 | 能否取消 | 说明 |
| --- | --- | --- |
| 未支付 | ✅ 可直接取消 | 不产生退款 |
| 已支付、尚未揽收/自寄验收 | ✅ 可取消 | 关闭未完成任务，生成全额退款流水 |
| 已揽收之后 | ❌ 不可普通取消 | 只能申请拦截 |

### 12.2 拦截

- 包裹被揽收后，客户可申请拦截。
- 包裹进入干线后，首版不支持中途变更目标网点；拦截请求记录为异常工单，待到达下一可操作网点后决定是否退回。

### 12.3 退回

退回状态流转：

```text
RETURN_REQUESTED → RETURN_APPROVED → RETURNING
→ RETURNED_TO_ORIGIN_STATION → RETURN_COMPLETED
```

- 退回使用新的运输段与必要任务，但仍关联原运单。
- 退回费用由异常规则决定，并记录原因与操作者。

## 十三、异常处理与派送失败

### 13.1 常见异常类型

揽收失败、地址错误、联系不上收件人、拒收、破损、重量不符、网点滞留、疑似丢失、等待补差价等。

### 13.2 派送失败处理（SOP）

1. **首次派送失败**（无人签收、联系不上）：派送员上报异常，系统记录。
2. **两次派送失败**：由运营管理员选择处理方式：
   - 重新派送：创建新派送任务，旧任务以失败原因关闭。
   - 改为网点自取：生成取件码，通知收件人自取。
   - 发起退回：进入退回状态流转。
3. **地址错误**：修改地址并重新匹配网点与计价。
4. **重量不符**：触发复价与补差价。

### 13.3 客户发起投诉或异常

- 客户可通过 AI 对话或客服渠道说明问题，经确认后创建异常工单。
- 异常工单按 OPEN → ASSIGNED → PROCESSING → WAITING_FOR_CUSTOMER → RESOLVED → CLOSED 流转。
- AI 创建异常工单前须征得客户确认。

## 十四、常见问题（FAQ）

**Q：充电宝能寄吗？**
可以，属限寄物品。单块额定能量不超过 100Wh（约 20000mAh），需独立绝缘包装，单次限寄 2 块，仅限陆运。

**Q：寄到上海多少钱？**
以北京—上海演示主线路为例：首重（1kg）15 元，续重每 0.5kg 加 6 元。上门揽收另加 3 元，网点自取减 1 元。具体以系统报价为准。

**Q：多久能送到？**
北京—上海主线路，上门揽收 + 送货上门为支付后 3 个工作日；网点自寄 + 送货上门为始发网点验收后 2 个工作日。

**Q：怎么查物流轨迹？**
登录后进入运单详情，可按节点时间线查看轨迹。干线阶段显示始发网点、目标网点、预计到达与剩余时间。系统不展示虚假的实时 GPS 位置。

**Q：可以寄酒吗？**
可以，属限寄物品。需原包装密封、防震，且符合限量要求。

**Q：寄的东西丢了怎么赔？**
已保价的按声明价值与实际损失较低者赔付；未保价的按运费 3 倍与实际损失较低者赔付（演示基线）。需保留凭证，由运营管理员判定。

**Q：下单后能取消吗？**
未支付可直接取消；已支付但尚未揽收或自寄验收的可取消并全额退款；揽收后只能申请拦截，不能普通取消。

**Q：取件码过期了怎么办？**
取件码默认 30 分钟有效，过期或输错 5 次锁定后，请联系网点人员核验收件人信息并重新签发。

**Q：哪些城市可以寄？**
目前支持北京、上海、广州、深圳四个城市及对应服务区。其他地区暂未开通。

**Q：可以寄活体动物吗？**
不可以。无法保证存活条件的活体动物属于禁寄物品。

**Q：可以寄现金吗？**
原则上不接受现金寄递。确需寄递的不享受保价且风险自担，建议使用其他方式。

**Q：周末能上门取件吗？**
营业时间为周一至周六 09:00—18:00，周日不计入工作小时，一般不在周日安排上门揽收。
