# 驿途首版计价规则

> 状态：演示基线 / 待运营确认  
> 版本：`pricing-demo-v1`  
> 生效时间：待运营确认后填写  
> 适用范围：北京、上海演示网点及同类国内线路  
> 货币：人民币，所有金额以分存储

## 1. 计价原则

1. 报价必须保存输入快照、命中的规则版本和费用明细；规则更新不得改变历史报价。
2. 第一版只支持一个实体包裹，不支持多包裹合单、危险品和跨境件。
3. 实际重量和尺寸由客户填写，揽收员或网点员可复核。复核后的计费重量变大时，进入补差价状态。
4. 不使用浮点金额。重量使用克，尺寸使用厘米，金额使用分。

## 2. 计费重量

```text
体积重量(克) = ceil(长 × 宽 × 高 ÷ 6000 × 1000)
计费重量(克) = max(实际重量(克), 体积重量(克))
计费档位 = ceil(计费重量 ÷ 500)
```

首重覆盖 1000 克；超过首重后按 500 克进位。例如计费重量 1.2 千克按 1.5 千克计算。

缺少重量或尺寸时只能生成待补充的预估报价，不能生成最终应付金额。

## 3. 演示区域价格

以下为非官方的可运行基线，运营确认后应写入带生效时间的价格模板：

| 区域线路 | 首重(1kg) | 每续重(0.5kg) | 说明 |
| --- | ---: | ---: | --- |
| 同城（北京-北京、上海-上海） | 800 分 | 200 分 | 同一城市服务区 |
| 普通跨区 | 1200 分 | 500 分 | 非偏远、非演示主线路 |
| 北京-上海演示主线路 | 1500 分 | 600 分 | 当前阶段标准演示路线 |
| 偏远地区附加 | +600 分 | +300 分 | 仅在区域规则命中时追加 |

区域匹配使用结构化地区编码，不使用地址文本模糊判断。当前演示地区：`110101` 对应北京，`310105` 对应上海。

## 4. 服务费用

| 项目 | 金额 | 规则 |
| --- | ---: | --- |
| 上门揽收 | +300 分 | `DOOR_PICKUP` |
| 网点自寄 | 0 分 | `STATION_DROPOFF` |
| 送货上门 | 0 分 | `HOME_DELIVERY`，已包含在基础运费 |
| 网点自取 | -100 分 | `STATION_PICKUP`，优惠不得使总价低于 0 |
| 保价 | 声明价值 × 0.3%，最低 100 分 | 未声明价值时为 0 |

最终金额：

```text
应付金额 = 首重费 + 续重费 + 区域附加费 + 服务费 + 保价费 - 优惠
```

报价接口必须返回分项明细、总金额、计费重量、规则版本和有效期；API 不接受客户端直接提交总金额。

## 5. 复重、补差价与退款

- 复核重量不变或变低：保留原报价，不自动退款。
- 复核重量变高：生成不可变的补差价流水；未补款前不得发车。
- 支付回调使用业务幂等键，重复回调返回原交易结果。
- 揽收前取消：全额退款；揽收后取消、拦截和退回的费用由异常规则决定，并必须记录原因。
